# Assets da marca Auto Orbital

Todos os arquivos desta pasta (e `../favicon.ico`) derivam do logo oficial aprovado
`frontend/src/assets/brand/logo-full.png` (1254x1254), apenas por recorte e redimensionamento
(Pillow). Nada foi redesenhado nem regenerado; bordas de recorte têm só um esmaecimento para o
fundo #010719.

| Arquivo | Uso |
|---|---|
| symbol.png (512) / symbol-128.png | símbolo (planeta, órbitas e cards), sem texto; barra lateral |
| wordmark.png | nome "AutoOrbital" (recorte do logo, fundo escuro convertido em transparência); login |
| favicon-16.png, favicon-32.png, ../favicon.ico (16/32/48) | favicon (recorte apertado planeta+anéis) |
| apple-touch-icon.png (180) | iOS |
| icon-192.png, icon-512.png | ícones PWA |
| icon-maskable-512.png | PWA maskable (símbolo na área segura de 80%) |
| og-image.png (1200x630) | pré-visualização social (logo full centralizado) |
